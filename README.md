## How I Use This Repository

For each lecture, I try to follow a simple approach:

1. Watch and understand the lecture.
2. Write the examples and programs myself.
3. Run the code and test it with different inputs.
4. Fix errors instead of simply replacing the code.
5. Add the useful programs to the corresponding lecture folder.
6. Revisit older programs when I need revision.

This helps me turn the course material into actual programming practice.
